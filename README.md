# 🎵 TUNEZZ — Music Without Borders

> A modern, responsive music streaming landing page designed to provide a smooth and engaging music discovery experience.

---

## 📌 Project Overview

**TUNEZZ — Music Without Borders** is a modern and responsive music streaming landing page developed using **HTML5, CSS3, and JavaScript**.

The website provides an interactive interface where users can explore trending songs, discover music by language, browse popular artists, explore playlists, and interact with a music player interface.

The main goal of this project is to create a visually appealing, responsive, and user-friendly music platform while gaining practical experience in frontend development.

### 🎯 Project Objectives

- Build a modern music streaming interface.
- Create a responsive website for different screen sizes.
- Provide simple and intuitive navigation.
- Implement interactive features using JavaScript.
- Practice frontend UI/UX development.
- Learn Git and GitHub workflow.
- Deploy the project using GitHub Pages.

## 📱 Responsive Design

The website is designed to provide a consistent experience across different devices.

TUNEZZ is optimized for:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

CSS media queries are used to adjust:

- Navigation
- Card layouts
- Spacing
- Content sections
- Font sizes
- Music player layout

This allows the website to adapt to different screen sizes while maintaining usability and visual consistency.

## ⚡ JavaScript Functionality

JavaScript is used to add interactive functionality to the website.

### 🔎 Song Search

Users can search for songs using the search bar.

The search functionality checks:

- Song name
- Artist name
- Language

Matching songs are displayed dynamically.

### 🌎 Language Filtering

Users can filter songs based on language to discover music from different languages.

### ▶️ Play/Pause Controls

The music player provides interactive Play/Pause controls.

The player state changes when the user clicks the Play/Pause button.

### ❤️ Favorite Management

Users can mark songs as favorites.

The favorite count is updated dynamically when songs are added to or removed from favorites.

### 📊 Music Progress Control

The music progress bar allows users to interact with the playback progress of the player interface.

### 🧭 Active Navigation

JavaScript is used to update the active navigation link based on the current section of the website.

### 📱 Mobile Navigation

The navigation menu adapts to smaller screen sizes to provide a mobile-friendly browsing experience.
